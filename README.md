نبذة عن المشروع

Qirvexa منصة ذكية لإدارة المشاريع والأعمال، تجمع المهام والعملاء والمواعيد والمتابعة المالية في مساحة عمل واحدة.

توفر لوحة تحكم تفاعلية بتصميم عصري، مع دعم اللغتين العربية والإنجليزية، وأدوات تساعد على تنظيم العمل ومتابعة الإنجاز واتخاذ القرارات بسهولة.

المميزات

- لوحة تحكم تفاعلية تعرض مؤشرات الأداء وتقدم المشاريع.
- إنشاء المشاريع وتعديلها وإدارتها ومتابعة حالاتها.
- إدارة المهام والمواعيد ونسب الإنجاز.
- تنظيم بيانات العملاء وربطها بالمشاريع.
- متابعة القيم المالية والمدفوعات والمبالغ المستحقة.
- رسوم بيانية وتقارير مستمدة من بيانات المشاريع.
- مساعد ذكي لإنشاء موجزات المشاريع وتنظيم الأفكار.
- بحث سريع وتصفية البيانات وتصدير تقارير CSV.
- تسجيل الدخول باستخدام Google وحفظ البيانات عبر Supabase.
- تصميم متجاوب يدعم الجوال والكمبيوتر.
- واجهة عربية وإنجليزية مع انتقالات سلسة.

التقنيات المستخدمة

React · TypeScript · Vite · Supabase · Cloudflare Workers AI · Recharts · Tailwind CSS

التشغيل محليًا

npm ci
npm run dev

لتشغيل خدمات الذكاء الاصطناعي محليًا عبر Cloudflare Worker:

npm run build
npm run dev:worker

راجع ".env.example" لإعداد متغيرات البيئة، وملفات "supabase/" لإعداد قاعدة البيانات والمصادقة.

«تدعم المنصة حسابات Google ومساحات عمل مستقلة للمستخدمين. بعض خدمات البريد الإلكتروني غير مفعلة حاليًا.»

About Qirvexa

Qirvexa is a bilingual project and business management platform designed to bring projects, tasks, clients, schedules, and financial tracking into one organized workspace.

It combines a modern interactive dashboard with intelligent tools to simplify workflows, monitor progress, and improve productivity.

Features

- Interactive dashboard with project insights and performance metrics.
- Project creation, editing, status tracking, and management.
- Task management, deadlines, and progress monitoring.
- Client profiles and project relationships.
- Financial tracking for project values, payments, and balances.
- Dynamic charts, reporting, and CSV export.
- AI-powered project brief generation.
- Advanced search, filtering, and quick navigation.
- Google authentication and Supabase cloud storage.
- Responsive layouts for desktop and mobile.
- Arabic and English language support.

Tech Stack

React · TypeScript · Vite · Supabase · Cloudflare Workers AI · Recharts · Tailwind CSS

Getting Started

npm ci
npm run dev

To run the Cloudflare Worker locally:

npm run build
npm run dev:worker

Configure environment variables using ".env.example".
